Profiles

A profile is a focus for the search: its own keywords, job titles and place. Fetch runs one profile or all of them, and every posting it finds is tagged with the profile, so you can filter the list by it. A posting found by two profiles carries both tags. Each profile you run uses its own requests on LinkedIn, Indeed and Adzuna, so keep the keyword lists short.
