How the AI queue works

The queue hands requests to an AI assistant as files in a folder, and takes its replies back the same way. It works with any assistant that can read and create files in that folder. WildThing never calls an AI itself.

Set it up

  1. Choose the work folder. It is now {{ folder }}. To share one queue with the phone app, link Google in Settings (section 5): WildThing then uses the WildThing folder in your Google Drive directly, the same one the phone uses, with no Drive for desktop. Without Google, set the AI work folder in section 4.
  2. WildThing writes AI_INSTRUCTIONS.md there the first time you send a request, with requests/ and replies/ beside it.
  3. Connect your AI to that folder. This differs between assistants: you need one that can read and create files there (for a Drive folder, one with access to that Google Drive).

Use it

  1. Send requests with the "Send to folder" buttons on a posting (resume, cover letter, interview prep) or on the Gap plan page. They gather in one batch.
  2. Tell your AI: "read AI_INSTRUCTIONS.md and process the pending batch". It writes one reply per request and a short report saying done, skipped or failed for each.
  3. Import: open the Queue page (it imports on its own) or press Import replies. Each reply is filed with its posting, exactly as if you had pasted it.
  4. Clean-up: after a reply is saved, its reply and request files are deleted. When a whole batch is in, its two TODO files go too, so after a normal run the folders are empty.

If something goes wrong

  • The AI cannot see the folder. It may be signed in to a different account than the folder belongs to. Share the folder with the account your AI uses, or point it at the right one.
  • A reply is not showing up. Check that the AI wrote it into replies/ under exactly the reply file name in the TODO. The Queue page says "Reported done, reply file not there yet" when the report lists it but the file is missing; a Drive-synced folder can take a minute to catch up.
  • Replies are in Drive but WildThing does not see them. With the narrow Drive access, Google lets WildThing see only files it created. Press Check Drive access in Settings; if your AI's files are not listed, choose "All of my Drive" and link again.
  • An item came back skipped or failed. The Queue page shows the reason your AI gave. Fix the cause (for example, paste the full posting text) and send it again, or press Remove.

Without a folder

Copy and paste always works with any assistant: use the "Copy for your AI" buttons, then paste the reply back on the same page.

Privacy

Request files contain your resume (unless your AI already holds it) and the posting text. They stay in the work folder, and in Google Drive if it is a Drive folder, until they are imported and deleted.
